LLM:大语言模型（大模型）
        原理：依据用户语句，通过预测词语逐渐补全回答（为什么大模型要一个词一个词输出答案）
Token:词元
        原理：大模型本质是数学函数，不认识人类文字，Tokenizer通过编码进行文字-数字转换，首先把用户问题切分成一个一个小片段token，再把每个token映射为数字token id，后由大模型接收并给出回答内容的tokenid，再由                  tokenizer翻译为token
Context:上下文
        原理：一段对话内追加问题时，本质上程序会把整段对话历史一起发过去，大模型会一起分析，类似记忆功能；
                   context window上下文窗口是context能容纳最大token数量；
                  RAG可以抽取问题中最匹配的几个片段交给LLM处理
Prompt:提示词
        原理：即语句；
                   User Prompt，用户输入，
                   System Prompt，后台配置
Tool:工具（外部函数）
        原理：用户提问，消息发给平台，平台给大模型此消息和对应工具，大模型会向平台调用有关工具指令，然后平台会调用此工具并拿到信息，返回给大模型，大模型再用人类文字给平台信息，平台再给用户结果
MCP:工具接入平台的统一规范（模型上下文协议）
Agent:自主调用工具能力
Agent Skill:预先指令

大语言模型处理流程：
大模型本质是数学函数，不认识人类文字，Tokenizer通过编码进行文字-数字转换，首先把用户问题切分成一个一个小片段token，再把每个token映射为数字token id，后由大模型接收，通过自注意力找token关系，从而进行预测词语，再给出回答内容的tokenid，再由tokenizer翻译为token
