# AI 基础概念笔记

## 1. LLM (大语言模型)
- **原理**：依据用户语句，通过预测词语逐渐补全回答（为什么大模型要一个词一个词输出答案）。

## 2. Token (词元)
- **原理**：大模型本质是数学函数，不认识人类文字。Tokenizer 通过编码进行文字-数字转换，首先把用户问题切成一个个小片段 token，再把每个 token 映射为数字 token id，后由大模型接收并给出回答内容的 tokenid，再由 tokenizer 翻译为 token。

## 3. Context (上下文)
- **原理**：一段对话内追加问题时，本质上程序会把整段对话历史一起发过去，大模型会一起分析，类似记忆功能。
- **Context Window**：上下文窗口是 context 能容纳的最大 token 数量；RAG 可以抽取问题中最匹配的几个片段交给 LLM 处理。

## 4. Prompt (提示词)
- **原理**：即语句。
- **User Prompt**：用户输入。
- **System Prompt**：后台配置。

## 5. Tool 与 Agent
- **Tool (外部函数)**：用户提问 -> 消息发给平台 -> 平台给大模型消息和对应工具 -> 大模型向平台调用工具指令 -> 平台调用此工具拿到信息 -> 返回给大模型 -> 大模型再用人类文字给平台信息 -> 平台再给用户结果。
- **MCP**：工具接入平台的统一规范（模型上下文协议）。
- **Agent**：自主调用工具能力。
- **Agent Skill**：预先指令。

## 大语言模型处理流程
大模型本质是数学函数，不认识人类文字。Tokenizer 通过编码进行文字-数字转换，首先把用户问题切成一个个小片段 token，再把每个 token 映射为数字 token id，后由大模型接收。通过自注意力找 token 关系，从而进行预测词语，再给出回答内容的 tokenid，再由 tokenizer 翻译为 token。
